## Project

### 재난별 대피소 플랫폼

서울시 Open API를 활용하여 재난별 대피소 정보를 제공하는

- VyOS 기반 네트워크 및 라우팅 구성

- Spring Boot 기반 서비스 구성
- 관리자 서버 접근 제어
